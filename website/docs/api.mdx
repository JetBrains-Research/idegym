## How these are produced

Both FastAPI apps expose `/openapi.json`. The committed schemas under
`website/static/openapi/` are generated from the real router definitions by
[`website/scripts/gen_openapi.py`](https://github.com/JetBrains-Research/idegym/blob/main/website/scripts/gen_openapi.py),
so the rendered docs match the code. Regenerate them with the project's Python
environment:

```shell
# from the repo root, with the project venv
python website/scripts/gen_openapi.py website/static/openapi
```

> This is a **static** interactive schema — you can read every endpoint, model, and
> example. To "try it out" against a live console, point a tool like `curl`, the
> [Python client](/architecture/client), or the [MCP interface](/reference/mcp) at a
> running orchestrator.
